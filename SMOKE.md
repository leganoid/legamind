# Финальный smoke-тест Legamind 0.1.0

Дата: 2026-11-01. Установленное приложение `C:\Program Files\Legamind\legamind.exe`,
MSI 4.18 МБ, схема БД 15, провайдер DeepSeek.

## Сценарии и результаты

### 1. Чат + запись файла с подтверждением — PASS

- Запрос: «Создай smoke-final.txt с текстом SMOKE_OK_777.»
- Появилось подтверждение записи; включено «больше не спрашивать», нажато «Разрешить запись».
- Файл создан, содержимое `SMOKE_OK_777`.
- В БД: разрешение `session_permissions(kind=write)`, вызов `write_file` привязан к `message_id`.

### 2. RAG: индексация и ответ — PASS

- Создан `smoke-rag.md` с токеном `SMOKE_RAG_888`.
- Команда `/index` → в индексе появился чанк этого файла (всего 8).
- Вопрос «Какой уникальный токен в файле smoke-rag.md?» → ответ `SMOKE_RAG_888`.
- Модель использовала `read_file` (вызов в истории инструментов); RAG-индекс доступен.

### 3. Перезапуск приложения — PASS

- После полного закрытия и запуска: история сессии на месте, карточка «Инструменты» видна.
- Запрос «Создай smoke-final2.txt с текстом SMOKE_TWO_999.»
- Модалка подтверждения **не появилась** (разрешение сохранилось), файл создан с нужным текстом.
- В БД вызов привязан к новому `message_id`.

### 4. Горячая клавиша Alt+C — PASS

- После перезапуска композер не находился через UIA, но `Alt+C` сфокусировал поле,
  сообщение отправилось, файл создан.

### 5. Самопроверка — PASS

Настройки → Приложение → «🔍 Проверить всё»:

- База данных: схема v15, доступна.
- Движок OpenVINO: отвечает на порту.
- Модели: локальных 4, облачных 2.
- RAG: проектов 1, чанков 9.
- Провайдеры: включено 1, ключи на месте.
- Интернет-поиск: включён, провайдер auto.
- Резервные копии: автокопий 1.
- Логи: папка существует.

### 6. Резервные копии — частично

- Автокопия присутствует: `backups/auto-*.db`, 1 шт.
- Файл зашифрован DPAPI, поэтому снаружи не открывается как SQLite — это ожидаемо.
- Восстановление из копии в этом прогоне **не выполнялось** (разрушающая операция).

### 7. Тур первого запуска — PASS

- При первом запуске показан тур «Сессии слева»; «Пропустить» закрывает и запоминает.
- Если процесс убить до закрытия тура, тур покажется снова — ожидаемое поведение
  (флаг сохраняется при завершении тура).

## Найдено и исправлено в ходе проверки

- Авто-поиск в интернете срабатывал на локальных файловых командах и писал ошибки в лог.
  Исправлено: локальные задачи (создай/прочитай/файл/расширения) не запускают поиск.
  Коммит `af0532d`.
