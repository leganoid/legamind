# Приватность Legamind

## Что хранится локально

- База данных: сессии, сообщения, память, навыки, настройки — в
  `%APPDATA%\com.legamind.app`.
- Логи приложения — в `%APPDATA%\com.legamind.app\logs`.
- Резервные копии — в `%APPDATA%\com.legamind.app\backups` (автокопии зашифрованы DPAPI).
- Ключи провайдеров — в Windows Credential Manager, в базе только ссылка.

## Что уходит вовне

- **Облачные модели**: текст запроса, история диалога в пределах контекста и вложения
  отправляются выбранному провайдеру по его API.
- **Интернет-поиск**: поисковый запрос отправляется выбранному поисковому сервису
  (Wikipedia, Stack Exchange, GitHub, arXiv, Tavily/Brave/Google/SearXNG — что настроено).
- **Локальные модели**: ничего не уходит, обработка на этом компьютере.

Приложение не отправляет телеметрию и не загружает логи на сервер. Автообновление,
если будет включено, обращается только к настроенному серверу обновлений.

## Как удалить данные

- Удалить приложение через «Параметры → Приложения».
- Удалить папку `%APPDATA%\com.legamind.app` вручную (сессии, настройки, копии, логи).
- Ключи удаляются в «Провайдерах» или через Windows Credential Manager.
