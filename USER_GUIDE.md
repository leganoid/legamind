# Legamind — руководство пользователя

Версия 0.1.0. Приложение для работы с локальными (OpenVINO) и облачными ИИ-моделями
на Windows.

---

## 1. Что нужно для работы

- Windows 10/11 x64.
- Ключ облачного провайдера (например, DeepSeek) **или** скачанная локальная
  OpenVINO IR-модель.
- Интернет — только для облачных моделей и интернет-поиска. Локальные модели работают
  без сети.

Python, Node.js и модели в установщик **не входят** — всё необходимое для движка уже
внутри.

---

## 2. Установка

1. Запустите `Legamind_0.1.0_x64_en-US.msi`.
2. Windows может показать предупреждение SmartScreen (установщик пока не подписан).
   Нажмите «Подробнее» → «Выполнить в любом случае», если доверяете файлу.
3. Установите приложение (по умолчанию — `C:\Program Files\Legamind`).
4. Запустите Legamind из меню «Пуск».

Данные пользователя хранятся отдельно от программы:
`%APPDATA%\com.legamind.app` — база, логи, резервные копии.

---

## 3. Первый запуск

При первом запуске показывается краткий тур из 5 шагов:

1. сессии слева;
2. модель и её роль;
3. композер;
4. проект и RAG;
5. настройки.

Тур можно пропустить. Вернуться к нему: **Помощь → «✨ Пройти тур заново»**.

Если модели ещё не подключены, в чате будет баннер «Нет доступных моделей» с кнопками
**Провайдеры** и **Модели**.

---

## 4. Подключение облачной модели

1. Откройте **Провайдеры**.
2. Нажмите **«Добавить провайдера»**.
3. Выберите пресет (DeepSeek, OpenAI, OpenRouter, Anthropic и т.д.) или «Свой».
4. Проверьте базовый URL.
5. Вставьте API-ключ.
6. Нажмите **«Проверить»** — приложение запросит список моделей.
7. Сохраните.
8. При необходимости нажмите **«Обновить модели»**.
9. Включите провайдера.

Ключ хранится в Windows Credential Manager, в базе — только ссылка на него.

### Роли моделей

В карточке провайдера раскройте **«Модели и их роли»**:

- **чат** — обычный диалог;
- **эмбеддинги** — модели для векторного поиска (интерфейс размечен, RAG пока на FTS5);
- **реранкер** — переранжирование результатов;
- **изображения** — генерация изображений.

В выборе модели в чате показываются только модели с ролью **чат**.

---

## 5. Локальная модель OpenVINO

Установщик не содержит моделей — скачайте их сами.

Нужна папка OpenVINO IR, в которой есть:

- `openvino_model.xml` (или `*.xml`);
- `openvino_model.bin` (или `*.bin`);
- файлы токенизатора, если они идут отдельно.

Добавление:

1. Откройте **Модели**.
2. Нажмите **«📥 Мастер импорта»**.
3. Выберите способ:
   - **📁 Папка** — указать готовую папку IR;
   - **🌐 Hugging Face** — скачать готовую OpenVINO IR-модель.
4. Проверьте название, устройство и лимит ответа.
5. Нажмите **«Добавить и перезапустить движок»**.

### Загрузка с Hugging Face

1. В мастере откройте вкладку **Hugging Face**.
2. Введите репозиторий, например
   `OpenVINO/Qwen2.5-1.5B-Instruct-int4-ov`.
3. Нажмите **«Проверить»** — приложение покажет число файлов, размер и наличие
   IR/токенизатора.
4. Нажмите **«Скачать и проверить»**.
5. Дождитесь загрузки (прогресс в мастере).
6. Проверьте параметры и добавьте модель.

Важно: репозиторий должен уже содержать **OpenVINO IR** (`openvino_model.xml` и
`.bin`). Конвертация из PyTorch внутри приложения не выполняется. Приватные и gated
репозитории Hugging Face не поддерживаются.

Для ручного добавления ниже есть форма «Папка модели» — она работает и без мастера.

### Ручное добавление папки

Форма **«Добавить локальную модель»** ниже мастера: выберите папку, название, устройство
и лимит токенов. Движок перезапустится, модель появится в списке и в выборе модели чата.

Удаление из списка не удаляет файлы модели.

### Что показывает карточка «Движок»

- RSS процесса движка;
- число моделей в реестре;
- какие модели загружены сейчас.

## 7. Работа в чате

### Отправка

- **Enter** — отправить;
- **Shift+Enter** — перенос строки;
- **Ctrl+Enter** — отправить;
- кнопка **«Стоп»** — остановить генерацию.

### Сессии

- **+ Новая** — создать сессию.
- **📌** — закрепить сессию (она всегда сверху).
- **✎** — переименовать.
- **✕** — удалить (с подтверждением).

Поиск слева ищет по названиям сессий и по тексту сообщений. Найденное сообщение
открывается с подсветкой.

### Сообщения

- **Копировать** — скопировать ответ.
- **Перегенерировать** — удалить последний ответ и получить новый.
- **Изменить** — отредактировать свой вопрос и отправить заново.

### Параметры

Кнопка **«Параметры»**:

- лимит токенов ответа;
- температура;
- режим рассуждений (зависит от модели).

### Пресеты

Меню **«✨ Пресеты»** в композере вставляет готовую инструкцию:

- Код;
- Анализ;
- Перевод;
- Резюме;
- План.

### Слэш-команды

Введите `/` и выберите команду:

- `/help` — список команд;
- `/index` — переиндексировать проект;
- `/clear` — очистить контекст сессии;
- `/compact` — сжать историю;
- `/remember` — сохранить факт в память;
- `/skills` — список навыков;
- `/skill` — включить/выключить навык;
- `/pwd` — рабочая папка проекта;
- `/workdir` — задать рабочую папку;
- `/export` — экспорт диалога;
- `/web` — поиск в интернете или включение/выключение поиска.

## 8. Проект и работа с файлами

### Выбор папки

Нажмите чип **«📁 Проект»** в шапке чата и выберите рабочую папку. Модель видит файлы
только внутри неё.

### Режимы и доверие

В меню проекта:

- режим: **чат / планирование / сборка / ревизия**;
- доверие:
  - **Только чтение** — модель не меняет файлы;
  - **Рабочая папка** — изменения только внутри проекта;
  - **Полный доступ** — можно выходить за пределы папки (осторожно).

### Подтверждение действий

Перед записью, удалением, переименованием или командой появляется окно:

- что будет сделано;
- diff для файлов;
- команда для `run_command`;
- кнопки **«Разрешить»** / **«Отмена»**;
- галочка **«Больше не спрашивать в этой сессии»**.

Разрешение запоминается в БД и переживает перезапуск. Сбросить:
**Проект → «🔓 Сбросить разрешения»**.

### Отмена и история

- **Проект → «↩ Отменить изменение»** — вернуть последнюю изменённую версию файла.
- **Проект → «История инструментов»** — что и когда вызывалось.

Все действия пишутся в `audit.log`.

## 9. RAG — поиск по проекту

RAG подмешивает в ответ фрагменты файлов проекта.

1. Выберите рабочую папку.
2. Нажмите **«📚 Индексировать»** или отправьте `/index`.
3. Задавайте вопросы по проекту.

Особенности:

- учитывается `.gitignore` рабочей папки;
- служебные каталоги (`.legamind`, `node_modules`, `target`, `dist`, `.git`) исключены;
- изменения файлов подхватываются автоматически;
- в промпте фрагменты подписаны `путь:строка`;
- включить/выключить RAG: **Проект → RAG**.

Если ответ не использует проект:

- проверьте, что индекс не пуст;
- переиндексируйте;
- убедитесь, что RAG включён.

### Векторный поиск (по смыслу)

1. Добавьте локальную модель эмбеддингов (OpenVINO IR) в «Моделях» **или** назначьте
   облачной модели роль «эмбеддинги» в «Провайдерах».
2. Настройки → Приложение → **Векторный RAG** → выберите модель эмбеддингов.
   Там же можно выбрать локальный **реранкер** — он переупорядочит найденные фрагменты.
3. Откройте проект → **🧠 Векторизовать проект** или введите `/vectors`.
4. Дальше после `/index` и изменений файлов векторы считаются автоматически.

Поиск становится гибридным: FTS5 по словам + векторы по смыслу, затем реранкер (если
выбран) переставляет кандидатов. Если модель эмбеддингов не выбрана, RAG работает как
раньше, только на FTS5.

## 10. Вложения

Кнопка **«📎 Файл»** в композере. До двух файлов, до 8 МБ.

Поддерживается:

- **текст и код** — содержимое передаётся модели;
- **PDF** — извлекается текстовый слой (сканы без текста не поддерживаются);
- **изображения** PNG/JPEG/GIF/WebP — передаются только vision-моделям.

Для изображений с обычной текстовой моделью появится объяснение, что модель не
поддерживает vision. Локальные OpenVINO-модели изображения не принимают.

Другие бинарные файлы отклоняются: приложение не анализирует hex/дампы.

Вложения видны плашками над полем ввода: имя, размер, **✕** для удаления.

## 16. Резервные копии и перенос

- **Ручная копия** — по умолчанию обычный SQLite-файл. Его можно открыть, перенести
  на другой ПК или восстановить.
- Галочка **«Шифровать ручную копию (DPAPI)»** — копия будет открываться только под
  вашей учётной записью Windows и не перенесётся на другой ПК.
- **Автокопии** создаются при запуске (не чаще раза в 24 часа), хранятся 5 последних,
  всегда зашифрованы DPAPI.
- **Восстановление** заменяет текущую базу и перезапускает приложение. Перед этим
  автоматически создаётся копия текущей базы.
- **Экспорт всех чатов (JSON)** — папка `exports` в каталоге данных.

## 20. Типичные проблемы

### «Нет доступных моделей»

Подключите провайдера (ключ) или добавьте локальную IR-папку в «Моделях».

### «Движок не отвечает»

- Настройки → Приложение → «Перезапустить движок».
- Проверьте `engine_stderr.log` в диагностике.
- Перезапустите приложение.

### Провайдер отвечает 401/403

Неверный или просроченный ключ. Откройте «Провайдеры» → «Изменить» → проверьте ключ.

### Модель не появилась после добавления

- В папке должны быть `.xml` и `.bin`.
- Нажмите «Перезапустить движок».
- Проверьте самопроверку.

### RAG не находит файл

- Файл должен быть текстовым и не превышать лимит размера.
- Проверьте `.gitignore`.
- Переиндексируйте проект.

### Изображение не принимается

Модель не заявлена как vision или локальная. Выберите vision-модель.

### SmartScreen предупреждает

Установщик пока не подписан. Для публичной раздачи нужен сертификат Code Signing.

### Где логи

Настройки → Приложение → Диагностика.

## 22. Быстрый старт за 5 минут

1. Установить MSI.
2. Открыть «Провайдеры» → добавить DeepSeek → вставить ключ → «Проверить» → включить.
3. Открыть «Чат» → выбрать модель.
4. Нажать чип «Проект» → выбрать папку.
5. Нажать «📚 Индексировать».
6. Написать задачу.
7. Если появится запрос на запись — проверить diff и разрешить.
8. Закрыть и снова открыть приложение — убедиться, что история на месте.

### Импорт чата

В боковой панели нажмите **📥** и выберите JSON или Markdown. Поддерживаются
массивы {role, content}, объект messages и заголовки User:/Assistant:.
Создаётся новая сессия «Импорт: имя файла»; лимит — 2 МБ и 500 сообщений.


### Папки сессий

У каждой сессии в боковой панели есть кнопка **📁**. Задайте имя папки — сессии
сгруппируются под заголовком; пустое имя убирает сессию из папки.


### Быстрый вопрос (оверлей)

Нажмите **Ctrl+Shift+Space** в любом приложении — откроется окно быстрого вопроса.
Выберите модель, введите вопрос, Enter. **Esc** скрывает окно.
