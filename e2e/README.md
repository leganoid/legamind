# E2E-тесты Legamind

Сквозной прогон установленного приложения на Windows через UI Automation:
реальный запуск `legamind.exe`, ввод в композер, подтверждение инструментов,
проверки по SQLite и файлам, перезапуск, самопроверка.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File e2e\run.ps1
```

Требования:

- установленное приложение `C:\Program Files\Legamind\legamind.exe`;
- провайдер DeepSeek с ключом (модель `deepseek/deepseek-flash`);
- Python из `%LOCALAPPDATA%\venvs\ai`.

Скрипт создаёт отдельный проект `.tools\e2e-project` и сессию «E2E smoke»,
после прогона удаляет сессию и разрешения. Отчёт пишется в `e2e\last-run.json`.

## Что проверяется

1. Подготовка сессии и проекта.
2. Запуск приложения и доступность композера (тур закрывается автоматически).
3. Запись файла с подтверждением + «больше не спрашивать».
4. Сохранение разрешения в БД и привязка вызова к сообщению.
5. RAG: `/index`, появление чанка, ответ с токеном из файла.
6. Перезапуск приложения и сохранение истории.
7. Запись после перезапуска **без модалки** (разрешение сохранилось).
8. Самопроверка в настройках: схема и RAG-индекс.

## Ограничения

- Это UI Automation, а не tauri-driver: чувствительно к фокусу окна и DPI.
- Не проверяет vision, добавление локальной модели и восстановление из копии.
- Для CI потребуется интерактивная сессия Windows (не headless).
