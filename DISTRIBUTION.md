# Подготовка к раздаче Legamind

## Что входит в установщик

- Само приложение (Tauri + WebView2).
- Автономный движок `legamind-engine.exe` (Python + OpenVINO внутри, Python на
  машине пользователя не нужен).
- Исходники `engine` оставлены как резерв для разработки.

**Чего в установщике нет и не должно быть:**

- локальных моделей OpenVINO IR (пользователь скачивает сам);
- API-ключей провайдеров (пользователь вводит сам);
- пользовательских данных и настроек.

## Что делает пользователь

1. Устанавливает MSI.
2. Подключает облачную модель: «Провайдеры» → добавить ключ → проверить → включить.
   Либо добавляет локальную модель:
   - скачивает/конвертирует OpenVINO IR (папка с `openvino_model.xml` и `.bin`);
   - «Модели» → «Добавить локальную модель» → выбрать папку;
   - движок перезапускается, модель появляется в чате.
3. Выбирает рабочую папку проекта (чип «Проект»).

## Сборка

```powershell
# 1. Движок в exe (PyInstaller, ~0.3 ГБ) → sidecar-dist/
powershell -ExecutionPolicy Bypass -File build-sidecar.ps1

# 2. Приложение и MSI
npx tauri build
```

Результат: `src-tauri\target\release\bundle\msi\Legamind_<версия>_x64_en-US.msi`.

## Код-сигнинг (обязательно для публичной раздачи)

Без подписи SmartScreen показывает предупреждение.

1. Получить сертификат Code Signing (OV/EV) у удостоверяющего центра.
2. Установить сертификат в хранилище Windows.
3. Подписывать одним из способов:
   - Tauri: `bundle.windows.certificateThumbprint` (отпечаток сертификата);
   - либо `signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a <файлы>`
     для `legamind.exe`, `legamind-engine.exe` и MSI.
4. Проверить: `signtool verify /pa /v <файл>` и запуск на чистой машине.

## Автообновление

1. Добавить `tauri-plugin-updater` в Rust и JS.
2. Сгенерировать ключи: `npx tauri signer generate`.
3. Настроить `plugins.updater`:
   - `endpoints`: URL манифеста обновлений;
   - `pubkey`: публичный ключ.
4. Публиковать подписанный манифест (`latest.json`) и новые MSI на сервере/в релизах.
5. Проверить обновление с предыдущей версии на чистой VM.

## Чистая Windows VM — обязательный тест

Проверить **без Python, без моделей, без ваших ключей**:

1. Установка MSI, запуск, отсутствие предупреждений.
2. Тур первого запуска.
3. Добавление провайдера с ключом, тестовый чат.
4. Добавление локальной модели (если есть IR) и чат с ней.
5. RAG по папке, запись файла с подтверждением.
6. Перезапуск: настройки/сессии на месте.
7. Самопроверка: все пункты зелёные или объяснимые.
8. Удаление приложения: данные в `%APPDATA%\com.legamind.app` остаются (это ожидаемо).

## Чек-лист релиза

- [ ] `build-sidecar.ps1` собран и проверен (`READY port=...`).
- [ ] Версия в `tauri.conf.json` и `package.json` обновлена.
- [ ] MSI собран на чистом окружении.
- [ ] exe и MSI подписаны, SmartScreen не блокирует.
- [ ] Манифест обновления опубликован.
- [ ] Пройден E2E (`e2e\run.ps1`).
- [ ] Пройден чек-лист на чистой VM.
- [ ] Есть текст лицензии/политики конфиденциальности.
- [ ] Указано, куда сообщать об ошибках.

## Ограничения текущей версии

- Только Windows x64.
- Локальные модели не скачиваются автоматически — нужна папка IR.
- Vision-модели: только облачные, заявленные как vision.
- RAG — FTS5 без векторных эмбеддингов.
